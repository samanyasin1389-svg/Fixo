# Persian repair-shop copy

## Goal

Write Persian the way Iranian phone-shop techs actually talk — informal but polite, not textbook.

## Language

- Default UI language: Persian (fa).
- Keep product/brand tokens: Fixo, Play, Wi‑Fi, APK, GitHub, ADB.
- Prefer مکالمهٔ مغازه over اداری:
  - خوب: «اکانت پلی آماده‌ست؟»
  - بد: «آیا حساب کاربری فروشگاه گوگل پلی شما آماده می‌باشد؟»
- Use short question + short action pairs.

## Install flow wording

1. «اکانت پلی روی گوشی آماده‌ست؟» → بله / بعداً
2. «از کجا نصب کنم؟»
   - خودکار (پیشنهادی)
   - گوگل پلی
   - فایل APK روی لپ‌تاپ
   - گیت‌هاب / لینک مستقیم

## Section titles (preferred)

- شبکه مغازه (not «مدیریت اتصال بی‌سیم»)
- برنامه‌ها (not «نصب سریع از استور»)
- بک‌آپ گوشی (not «پشتیبان‌گیری رسانه»)
- گفتگو (acceptable: Agent فقط اگر کنار برچسب فارسی باشد)

## Error messages

Say what failed and the next physical step:

- «وصل نشد. USB debugging و اجازهٔ این کامپیوتر را روی گوشی چک کنید.»
- «پلی باز شد ولی نصب کامل نشد. روی گوشی Install/نصب را بزنید.»
- «فایل APK پیدا نشد. مسیر فایل را در کاتالوگ بگذارید.»

## Do not

- Mix Farsi and English mid-sentence when a clean Persian phrase exists.
- Use کسرهٔ اضافهٔ سنگین یا جملات چند‌بندی برای یک دکمه.
- Invent slang that confuses older techs.
