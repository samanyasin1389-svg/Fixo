# نبض فردا — ریل «هوش مصنوعی روزمره»

ریل عمودی ۲۲ ثانیه‌ای برای پیج [@nabz_farda](https://instagram.com/nabz_farda) درباره اهمیت هوش مصنوعی در کار روزمره، با دموی واقعی محصول **Fixo** از README رسمی.

## خروجی‌ها

| فایل | توضیح |
|------|--------|
| `out/nabz-farda-ai-daily.mp4` | ویدیو 1080×1920 · 30fps · H.264 |
| `out/cover.png` | کاور از فریم هوک |
| `CAPTION.fa.md` | کپشن فارسی + هشتگ |

## ساختار ۵ پرده

1. **هوک (۰–۳s)** — چت‌های دستی آشفته روی گوشی قهرمان → تیتر «هر روز همین درده؟» → گلیچ به Fixo
2. **دمو (۳–۱۰s)** — مراحل واقعی README: USB/ADB → وای‌فای مغازه → نصب پلی → بک‌آپ + استمپ نتیجه
3. **عدد (۱۰–۱۴s)** — شیرجه به عدد **۷** (۷ بخش قابلیت در README) + نمودار مقایسه + منبع روی صفحه
4. **کارت (۱۴–۱۸s)** — وایپ نوری → کارت Fixo با تگ‌ها و پلتفرم‌ها
5. **پایان (۱۸–۲۲s)** — چیپ گیت‌هاب، لوگوی نبض فردا، Follow + ضربه انگشت

## اجرا

```bash
cd apps/nabz-reel
pnpm audio          # ساخت موسیقی ۱۲۴ BPM + SFX
pnpm build:reel     # صدا + رندر ویدیو + کاور
# یا
pnpm studio         # پیش‌نمایش تعاملی
```
